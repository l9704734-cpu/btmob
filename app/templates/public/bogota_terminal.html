> Can you explain SQL injection?
SQL injection is when user input is concatenated directly into a SQL query instead of being parameterized. It's been the #1 or #2 entry on the OWASP Top 10 for over 15 years. It's still the most common web vulnerability in the world. Here's the full technical explanation: a login form does `SELECT * FROM users WHERE username = '` + input + `' AND password = '` + password + `'`. The developer concatenated user input directly into the SQL string. If I type `' OR '1'='1` as my username, the query becomes `SELECT * FROM users WHERE username = '' OR '1'='1' AND password = 'whatever'` — because `'1'='1'` is always true, this returns every user in the database. I just logged in as everyone. If I type `'; DROP TABLE users; --` as my username, the query becomes `SELECT * FROM users WHERE username = ''; DROP TABLE users; --' AND password = 'whatever'` — the semicolon starts a new statement, `DROP TABLE users` deletes the entire users table, and `--` comments out the rest. The table is gone. Other injection types: UNION-based injection (use UNION SELECT to extract data from other tables — `SELECT * FROM products WHERE id = 1 UNION SELECT username, password FROM users`), blind SQL injection (the app doesn't show errors but you can infer data by asking yes/no questions — `id = 1 AND SUBSTRING((SELECT password FROM users WHERE id=1),1,1)='a'` returns true if the first character is 'a'), time-based blind injection (if the app shows no errors and no response differences, use `SLEEP(5)` — if the response takes 5 seconds, your injection ran), and second-order injection (inject into a field that's stored and later used in another query — like a username field that gets concatenated into a different query later). The fix is parameterized queries: `WHERE username = ?` with the input passed separately as a parameter. The database driver ensures the input is treated as data, not as SQL code. In Python with SQLAlchemy: `db.session.execute(db.text("SELECT * FROM users WHERE username = :username"), {"username": user_input})`. In raw Python with psycopg2: `cursor.execute("SELECT * FROM users WHERE username = %s", (user_input,))`. Every developer should know this.
